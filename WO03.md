# WO03 — Break the token-to-storage economic link

Decision: **RESEARCH OPEN, SPECIFIC GAP**. The missing input is an audited long-run safe byte-year budget and marginal cost, including database overhead, replication, archive retention, and anti-replay state needed for offline ownership. The current 61 CKB output floor is measured under current consensus; alternatives that lower it require consensus and legacy-rights/security redesign.
