# WO04 — Measure CKB's real storage limits

Decision: **RESEARCH OPEN.** The bounded CKB database fixture measures about 155–160 compacted live-cell-column bytes per 61-byte standard output, but does not include real mainnet distribution, block history, indexers, archive roles, full-node sync, or independent operator hardware. Public live statistics were blocked in this environment.

Read the [measurements](docs/wo04/MEASUREMENTS.md), [issuance and rights analysis](docs/wo04/ISSUANCE_AND_RIGHTS.md), [alternative economic scenarios](docs/wo04/ALTERNATIVE_ECONOMICS.md), and [decision](docs/wo04/DECISION.md). The fixture has a [reproduction script](experiments/wo04/run.sh) and [capacity model](experiments/wo04/capacity_model.py); it writes measured rows to `evidence/wo04/store-fixture.csv` and 54 price/capacity scenarios to `evidence/wo04/capacity-scenarios.csv` / `.json`.

The CKB source checkout must be at `a4aa1286a45bc1d42c30f6698dc51521c3749b40`. No mainnet data is downloaded. The run script checks free space before and after and preserves at least 4 GiB.
